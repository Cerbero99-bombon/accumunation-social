# accumunation-social

Solo i media pubblici di Accumunation: le immagini e i video che Instagram, Facebook e Threads
devono poter scaricare da un URL aperto per pubblicarli.

**Qui non c'e' altro.** Copioni, dati, prezzi, registri, codice e coda di pubblicazione stanno nel
repo privato `accumunation-media`.

Creato il 26/08/2026 spaccando in due il vecchio repo, che era pubblico per intero.
